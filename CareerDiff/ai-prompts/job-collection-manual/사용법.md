# 사용법 - 채용정보 수동 수집 (JobCollect)

## 1. Claude/ChatGPT Project 만들기

```text
Project Name: JobCollect
Project Instructions: 지침.md 내용 전체를 그대로 붙여넣는다
Knowledge 첨부: COLLECT_PROMPT.md
계정 메모리(Settings → Memory): 메모리.md 내용을 붙여넣는다
```

`CareerDiff` 분석 Project와는 다른 새 Project다 — 같은 Project에 두 지침을 섞지 않는다(역할이
다르면 프롬프트 규칙도 서로 오염될 수 있다).

ChatGPT는 화면에 따라 별도 지침 입력칸이 없을 수 있다. 그럴 때는 새 채팅 첫 메시지로 `지침.md`
내용을 그대로 보내고, `COLLECT_PROMPT.md`를 프로젝트 파일로 첨부한다.

## 2. 공고 1건 수집

1. 채용 사이트에서 관심 있는 공고 페이지를 사람이 직접 연다(스크립트/자동화 없음).
2. 공고 본문을 복사해 `COLLECT_PROMPT.md`의 "복사할 프롬프트" 틀에 붙여넣는다(URL도 있으면 채운다).
3. Project에서 실행한다.
4. 받은 응답이 JSON 코드블록 하나인지 확인한다(설명 문장이 붙어 있으면 "JSON만 다시 출력해줘"로
   재요청).

## 3. 결과 저장

1. JSON을 다운로드하거나 복사해서 새 파일로 저장한다.
2. 파일명 규칙: `NNN_YYYYMMDD_회사-직무.json` (예: `001_20260801_카카오-백엔드.json`)
3. `collected-jobs/` 폴더에 저장한다(이 폴더는 git에 커밋되지 않는다 — `.gitignore` 참고).
4. `COLLECT_LOG.md`에 한 줄을 추가한다: 번호, 날짜, 회사명, 직무, 카테고리 태그, 원문 URL.
   **공고 본문 전체나 상세 요건 문장은 로그에 옮겨 적지 않는다** — 로그는 git에 커밋되므로
   메타데이터만 남긴다.

## 4. 검증 체크리스트 (결과 저장 전)

- [ ] 최상위 키가 스키마와 정확히 일치 (`COLLECT_PROMPT.md` 참고)
- [ ] `categories`가 고정 목록(AI/데이터/백엔드/프론트엔드/리더십/해외주재/기타) 안에서만 채워짐
- [ ] 원문에 없는 회사 정보·마감일·요건이 지어내지지 않음(원문과 대조)
- [ ] 명시 안 된 필드는 `null`/빈 배열로 남아 있고, 임의로 채워지지 않음
- [ ] `summary`가 한국어(고유명사 제외)
- [ ] `techKeywords`가 원문 표기 그대로(번역/정규화 없음)

## 5. 목표

정해진 개수 제한은 없다 — 이 트랙은 `jobkorea-ai/`가 자동으로 하던 일을 사람이 필요할 때마다
수동으로 대체하는 것이라, 실제로 관심 있는 공고를 발견할 때마다 그때그때 쌓으면 된다. 다만 나중에
`build_trend_report.py`(제거됨)가 하던 것과 비슷한 트렌드 집계를 다시 하려면 최소 표본이 필요하니,
`README.md`의 목적을 참고해 필요에 따라 스스로 목표량을 정한다.

## 참고 파일 관계

```text
지침.md              - Project Instructions에 넣는 지침 (이 폴더)
메모리.md            - 계정 단위 Memory에 넣는 문구 (이 폴더)
COLLECT_PROMPT.md    - Knowledge에 첨부하는 실제 프롬프트+스키마
COLLECT_LOG.md       - 수집 메타데이터 로그 (git 추적, 공고 본문 없음)
collected-jobs/       - 구조화된 결과 JSON 누적 폴더 (git 미추적)
README.md            - 이 트랙이 왜 존재하는지 + 절대 원칙(자동화 금지 등)
```
