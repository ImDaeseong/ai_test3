# Verification

## 명령

```powershell
cd app
npm run typecheck
npm test
npm run build
npm run test:e2e
```

## 필수 검증

- 잡코리아 허용 URL과 거부 URL
- 공개 HTML에서 한글 제목·회사명·본문 추출
- 후보자 JSON 첨부, 잘못된 JSON 거부, 새로고침 복원
- 분석 요청 스키마와 결과 스키마
- 미니 프로젝트 정확히 3개
- 프롬프트 인젝션 방어 및 비요구사항 문단 제외 규칙
- 검증 JSON 생성, 동일 ID 중복 방지, 경로 이탈 차단
- 프로덕션 빌드와 주요 브라우저 흐름

## 분석 품질 검토

`data/*.json`에서 입력과 결과를 함께 확인한다.

- 없는 경험을 만들지 않았는가
- 필수와 우대를 구분했는가
- 점수와 설명이 입력 근거와 일치하는가
- 약점, 프로젝트와 면접 질문이 실제 공고에 연결되는가
- 반복 실행 시 중대한 결과 변동이 없는가

## HOLD 조건

- 로그인, CAPTCHA 또는 접근통제 우회가 필요함
- 실제 후보자 데이터가 로그나 외부 서비스로 의도치 않게 노출됨
- 저장 파일이 프로젝트 `data` 밖에 생성됨
- 같은 검증 항목이 세 번 연속 실패함
- 유료 API 사용 전 로컬 검증 데이터가 충분히 검토되지 않음
